# **App Name**: Campus Compass

## Core Features:

- Interactive Map: Interactive campus map with clickable buildings and points of interest.
- Virtual Tour: Virtual Tour: Explore campus from anywhere with a guided virtual tour.
- Smart Assistant: AI Chatbot: Answer common questions from prospective and current students.
- Event Listings: Event Calendar: See a calendar of upcoming events.
- Student Portal: Personalized dashboard for logged in students with important notifications, class information, etc.
- Data Integration: Integration with the university's existing event management systems for the latest and most up-to-date listings.

## Style Guidelines:

- Primary color: Deep blue (#3772FF) to convey trust and knowledge.
- Background color: Very light blue (#F0F4FF), near white, providing a clean, uncluttered backdrop.
- Accent color: A vivid violet (#9757D7) to highlight key actions and information.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use consistent, modern line icons to represent different campus services and resources.
- Employ a clean, grid-based layout with plenty of whitespace to improve readability.
- Use subtle animations for transitions and interactions to guide the user's attention without being distracting.
